# Storage and interface contract

- Runtime backend: LanceDB only; no PostgreSQL connection string or backend selector. The server/local administrator uses AGENTIX_LANCE_PATH (XDG fallback); laptop MCPs and remote ingesters use AGENTIX_STORE_URL with an optional runtime credential instead. Remote mode never opens a local directory. A stale PG_DSN without explicit local or remote configuration fails clearly. See [HTTP contract](http.md).
- EMBED_MODEL/EMBED_DIMENSIONS must match persistent schema metadata. Defaults are jina-code-embeddings-1.5b Q8_0 / 1536. LANCE_NPROBES=20 (1..64), LANCE_EF=100 (100..400).
- MCP names, parameter names and formatted row types remain. Limits are validated as 1..100. Code filters: language/symbol kind/exact or LIKE repository/project whitelist. Docs: kind/projects. GitHub: entity type/repository/state, with the existing unscoped project contract. Reranking remains outside storage.
- Keyword ranks native FTS hits; hybrid combines up to 60 (or requested limit if larger) lexical/vector candidates using RRF k60 and stable key tie-breaking. Filters precede retrieval. get_file orders chunk_index; repository/file counts respect project visibility.
- ingest retains code/docs/github/hackage/crate/pypi/git/list/prune, adding import/optimize/stats/sync-status. A busy writer, unavailable embedding service, invalid vector/schema/model, failed sync stream or storage failure returns nonzero; old file data is preserved until its replacement is ready.
- Legacy JSONL import records contain table,row,embedding. embedding is a PostgreSQL vector-text JSON array string or null. All six collections plus repo_index/sync_state are supported. Fresh destination and explicit model assertion required; unsupported records/invalid dimensions fail. Complete manifest includes source SHA-256 and expected counts.
